Demo videos should be generated by running:
  npm run playwright

Expected videos (15-40 seconds each, 1280x800):
1. 1-installation-onboarding.webm - Installation and onboarding page walkthrough
2. 2-send-to-docs.webm - Using the Send to Docs button on an AI answer
3. 3-popup-settings.webm - Extension popup and settings interface

Convert to MP4 with:
  ffmpeg -i input.webm -c:v libx264 -preset slow -crf 22 output.mp4

Note: Videos use fixture HTML pages since live google.com cannot be reliably automated.
